MLCouncil Architecture

Pipeline batch-first per paper trading e backtest: ingest → feature store → modelli → council → portfolio/risk → execution, con feedback loop per drift e online learning.

Daily path

  • • Ingest OHLCV, news e macro.
  • • Calcola feature PIT su ArcticDB con shift anti-lookahead.
  • • Produce segnali LightGBM, FinBERT e HMM.
  • • Il council applica EWM IC-Sharpe + ortogonalità.
  • • Conformal sizing, CVXPY e risk gates portano agli ordini.

Backtest + online learning

  • • Walk-forward/snapshot per confronto storico.
  • • `MLCOUNCIL_ENV_PROFILE=frontier` abilita `MLCOUNCIL_ONLINE_LEARNING=true`.
  • • Il refit incrementale aggiorna il champion LightGBM quando il gate IC passa.
  • • Output: equity, weights, attribution, summary e artifact bundle.

Control plane

  • • FastAPI admin per health, pipeline, portfolio, config e monitoring.
  • • Streamlit per performance e confronto snapshot.
  • • Dagster orchestra il grafo asset-based.
  • • MLflow conserva metriche, SHAP e lineage sperimentale.
